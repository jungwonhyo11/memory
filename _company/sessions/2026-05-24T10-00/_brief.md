# 📋 작업 브리프

**원 명령:** 이미지를 만들는 도구를 만들어조

## 요약
사용자가 요청한 '이미지 생성 도구' 개발을 위해 기술 스택 선정, UI/UX 설계 및 실제 구현 코드를 작성합니다.

## 분배
- **💻 코다리**: 이미지 생성 AI API(DALL-E 3 또는 Stable Diffusion)를 통합한 웹 기반 이미지 생성 도구의 풀스택 코드를 작성하고, 프론트엔드 UI와 백엔드 API 연결 및 테스트 루프를 구현하라.
- **🎨 Designer**: 이미지 생성 도구의 사용자 인터페이스(UI) 브리프를 작성하라. 프롬프트 입력창, 스타일 선택 옵션, 결과물 전시 영역을 포함한 직관적인 레이아웃과 컬러 가이드를 제시하라.
