# 평가기준

## 공통 기준 (Code Convention)

- GEN-001: 함수는 단일 책임 원칙. 50줄 초과 시 분리 검토
- GEN-002: 매직 넘버 금지. 상수로 선언
- GEN-003: 에러 핸들링은 발생 지점에서 처리

## 이번 작업에 적용되는 ADR

ADR-005 (에러 처리 계층화) 간접 적용:
- 에러 발생 시 의미있는 정보를 반환해야 하며, console.log로만 끝내면 안 됨
- test.js는 이를 의도적으로 위반하여 리뷰 지적 대상으로 포함

## 논의 사항
- test.js가 JS이므로 TS 관련 규칙(TS-001~004)은 이번 리뷰에서 제외
